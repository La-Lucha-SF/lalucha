# Refrigeración La Lucha — Catálogo digital interactivo (demo)

Catálogo minimalista enfocado en vender por WhatsApp.

- **Catálogo:** cada producto muestra foto, código SKU y botón "Consultar" con el mensaje
  "Hola, deseo consultar disponibilidad del producto SKU: [código]".
- **Panel del dueño:** resumen con gráficas, botón "Cargar catálogo" para subir el archivo de A2
  (.xlsx, .xls o .csv) con reconocimiento automático de columnas, asignación de fotos por SKU
  y publicación con un clic.

Es un demo: todo funciona en el navegador y los cambios no se guardan en un servidor.
